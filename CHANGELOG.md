# Changelog

Notable changes to NEXUS are documented here.

## Unreleased / initial foundation

- Added a dark desktop shell with Overview, Quests, Habits, Focus, Finance, and Journal pages.
- Added local SQLite persistence for tasks, habits, check-ins, transactions, journal entries, and focus sessions.
- Added XP rewards for completed quests.
- Added 15, 25, 45, and 60-minute focus presets.
- Added database backup and portable JSON export.
- Added automated tests for database workflows and exports.
- Added GitHub Actions test workflow and Windows executable build workflow.
- Added README, MIT license, contributor guidance, and issue templates.
